# מערכת ניהול המכון

מערכת לניהול לידים, לקוחות וצוות היועצות של המכון. הממשק כולו בעברית, ומתאים למחשב, לטאבלט ולטלפון.

## מצב נוכחי: הדגמה בלבד

בשלב הזה אין מסד נתונים. כל המידע נשמר בדפדפן שבו עובדים בלבד:
- **לא להזין מידע אמיתי של לקוחות.** מי שיש לו גישה לדפדפן יכול לקרוא את המידע.
- **המידע לא משותף:** מה שמוזן במחשב אחד לא מופיע במחשב אחר.

במסך הכניסה יש כפתורי כניסה מהירה בשלושה תפקידים: מנהלת ושתי יועצות. כך אפשר לראות מה כל אחת רואה. הסיסמה של כל משתמשות הדוגמה היא `12345678`.

## מה יש במערכת

| חלק | מי רואה | מה אפשר לעשות |
|---|---|---|
| דף הבית | כולן | משימות להיום, פגישות בשבוע הקרוב, התראות |
| לידים | מנהלת בלבד | קליטת פנייה, מקור וסטטוס, תיעוד שיחות, מעקבים, בדיקת כפילויות, הפיכה ללקוחה |
| לקוחות | מנהלת: כולן. יועצת: רק המשויכות אליה | כרטיס אישי: שלבי התהליך, פגישות וסיכומים, תיעוד, אבחונים עם קבצים, משימות, סיום ומשוב |
| משימות | כל אחת את שלה. המנהלת רואה את כל הצוות | משימות ומעקבים לפי תאריך |
| צוות והרשאות | מנהלת בלבד | הוספת משתמשת עם סיסמה זמנית, איפוס סיסמה, השבתה, שינוי תפקיד |
| הגדרות | מנהלת בלבד | עריכת מקורות הגעה, סטטוסים של לידים ושלבי התהליך, ויומן פעולות |

## אבטחה

- כל בדיקות ההרשאה נעשות בשכבת הנתונים, לא רק במסכים. הסתרת כפתור לא נחשבת הרשאה.
- הכניסה ננעלת ל-5 דקות אחרי 5 ניסיונות שגויים.
- אחרי 30 דקות בלי פעילות המשתמשת יוצאת מהמערכת אוטומטית.
- לקוחות ולידים לא נמחקים אלא עוברים לארכיון. פעולות רגישות נרשמות ביומן.

## הרצה במחשב (למפתח)

| פקודה | מה היא עושה |
|---|---|
| `npm install` | התקנת הספריות |
| `npm run dev` | הפעלת השרת המקומי בכתובת `http://localhost:5173` |
| `npm test` | הרצת הבדיקות האוטומטיות של ההרשאות |
| `npm run build` | בניית גרסה להעלאה לאוויר |

## מבנה הקוד

| תיקייה | מה יש בה |
|---|---|
| `src/core` | סוגי הנתונים, כללי ההרשאות ובדיקת התקינות של השדות |
| `src/data` | שכבת הנתונים. `DataService.ts` הוא החוזה, ו-`local/` הוא המימוש הזמני בדפדפן |
| `src/modules` | כל חלק במערכת בתיקייה משלו. חלק חדש נוסף ב-`registry.ts` |
| `docs/` | תיעוד, כולל תוכנית החיבור למסד הנתונים |
